# WARREN — Field Study 002 · Present ↔ Past

Open https://www.matchzimmerman.com/WARREN/experience/

Press **M** while walking or click **MAP / TODAY**. The panel shows current-day satellite or roads/terrain imagery with a reference for present-day Warren Road Bridge. Pan/zoom and click an area to move to the corresponding *estimated* coordinate in the explorable scene. On mobile, tap the map. The map button closes the panel; use the browser's Escape key to free your cursor if necessary.

**Geographic warning:** Only one modern geographic anchor has been used (Warren Road Bridge: approximately 39.4886,-76.6094). The artist's 1915 Bromley-derived scene remains in unregistered pixel-relative coordinates; orientation, scale, old crossing and river/terrain morphology are unverified. Treat all teleport mappings as subjective orientation exercises, **not identification of a ruin, historical building or original position**. The current aerial imagery is real; the corresponding historical geometry is not yet surveyed. External Google Maps link available for comparison. The Esri tiles load only with internet access. Imagery source attribution displayed inside the map.

This version leaves walk controls and original aesthetic intact. The original build is preserved in `experience/001/index.html`; `experience/map.js` is this experimental orientation layer. The GIS research workbench in `WARREN/` continues independently.
