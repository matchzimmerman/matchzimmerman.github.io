# Infinite Seconds

A single shared counter measuring the seconds elapsed since launch.

- Launch origin: `2026-08-01T04:28:33.000Z`
- No database or server process
- Every visitor derives the same count from the fixed launch timestamp
- Responsive 3 × 7 lo-bit numeral rendering on `<canvas>`
- Five deterministic high-saturation palettes
- Palette changes every 10 seconds, or every 60 seconds when reduced motion is preferred
