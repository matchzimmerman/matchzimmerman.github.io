A new MZTV browser-source piece that keeps the long-form evolving engine, but shifts the surface language closer to the OBAS mp4 branch from the conversation.

## Intent
- Keep the MZTV live, ever-evolving organism behavior.
- Use the OBAS visual identity more directly: cream paper ground, navy structural bands, coral contour activity, teal accent events.
- Keep the field more pattern-forward and OBAS-derived rather than leaning too far into generic cymatic topography.

## Core behavior
- 4-color low-resolution field rendered at 480x270 and nearest-neighbor scaled to 1920x1080.
- Shared audiovisual state drives both image and sound.
- Visual events include quiet, torsion, shear, chevron, compression, and plateau states.
- Common-tone harmonic movement across Dm9, G6/9, Cmaj9, Am9, and Em11.
- Higher pad + sub structure with gliding harmonic shifts for long-form listening.
- HUD can be hidden with ?hud=0.
- Autostart audio can be disabled with ?audio=0.
