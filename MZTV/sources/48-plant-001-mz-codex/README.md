## Controls

- **Play 48 hours** advances from the current hour; the entire lifecycle takes 96 seconds.
- **Specimen desk** opens the timeline, From seed, Mature specimen and 4K still export.
- `?hour=8` starts at a selected hour (0–48).
- `?broadcast=1&hour=48` hides control chrome for a specimen display.

The preview opens at hour 24. Playback stops at hour 48. A page reload returns to the requested/default hour. The original local live specimen retains its own persistent life; this public page neither controls nor restarts it.

## What is replayed

`specimen-v1.json` contains 41 KB of final immutable geometry, leaf birth conditions, texture seeds and dormancy transitions from the original authored environmental score. The renderer filters historical tissue by birth minute and interpolates emergence. It is not a video. This is a fixed specimen replay, not a remote instance accepting new environmental inputs.

All 2,881 integer-minute render states were checked against the original Python growth engine. The original build's 13 model/API tests passed before publication. Public geometry excludes private source URLs, titles, local paths and live records.

## Source

`art-v1.js` contains the renderer and public replay controls. `style-v1.css` implements the responsive display. The independent local build uses an authoritative Python server, SQLite state, environmental intake and deterministic reconstruction. Its source remains preserved separately as version 1.0. This public viewer is an additive publication, not a replacement for that live runtime.
