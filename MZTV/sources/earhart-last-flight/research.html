02 / ANALYZE · EXECUTABLE SURROGATE

Flight integrator: Time-stepped kinematics, with a fixed planned bearing towards Howland plus seeded heading bias and procedural oscillation. Time step is 0.12 hours. East-west and north-south wind components are added to position increments using an equirectangular local approximation, not a full geodesic propagation.

Fuel: The model subtracts an assumed constant fuel burn (gallons/hour). Flight stops when assumed fuel is exhausted, or after a 27-hour hard limit. There is no altitude dynamics, tank selection, lean mixture, engine damage, actual fuel-log input, visibility, radio propagation, pilot strategy or aerodynamics.

Navigation: Beginning at model hour 18, an illustrative 157°/337° line-of-position search pattern alternates headings. This is a *stylized assumption*, not a reconstruction of documented actions. The simulation never has an omniscient steering correction towards Howland. The assigned Lae/Howland/Nikumaroro coordinates are approximate geospatial reference locations, not historical flight fixes.

Ensemble: 192 deterministic pseudo-random trials, eight disclosed during each of 24 two-hour epochs. Random draws are a convenient exploratory stress test, NOT a historically justified distribution of wind, navigation or fuel uncertainty. Consequently a trial fraction MUST NOT be interpreted as probability of where Earhart crashed.

03 / INTERPRET · WHAT COUNTS AS EVIDENCE

  • Documented: Historical information traceable to primary records, cited publications, or verified survey coverage, with associated uncertainty.
  • Derived: Calculations on documented measurements, with methods and sensitivity analysis.
  • Hypothetical: The current model's physical parameters, flight decisions, displayed engine sounds, trajectories, and geographic endpoints.
  • Unverified: Unlocated objects, anomalies in imagery, conjectured wreck sites, and proposed interpretations until independently substantiated.

Colors on the map differentiate reference waypoints and experimental samples. Neither brightness nor density means validated likelihood. The density layer is only a count of generated endpoint occurrences within an uncalibrated sample.

04 / RETURN · NEXT BUILD GATES

  1. Provenance gate: Import archived primary flight records and engineering drawings with file hash, page locator, extraction notes, licensing and uncertainties.
  2. Validation gate: Build a JSBSim Lockheed 10E definition, separately confirm its geometry, tank map, engine/propeller performance and fuel burn, then back-test documented flight legs.
  3. Weather gate: Reconstruct meteorological inputs and represent epistemic uncertainty explicitly rather than injecting arbitrary wind.
  4. Search coverage gate: Audit actual bathymetric, sonar, ROV, aerial, LiDAR and historical photographic datasets for location, resolution, dates, completeness and usage rights.
  5. Inference gate: Constrain any ensemble with dated observations; perform out-of-sample and parameter sensitivity checks before producing a search-priority map.
  6. Broadcast gate: Add a state service for shared timeline and counterfactual experiments; connect MZCAM and OBS; deploy a telephony gateway with authenticated webhooks and private DTMF interactions. The current browser keypad is local only.

05 / PRODUCTION + REPRODUCIBILITY

Open the broadcast. OBS can capture index.html?obs=1&audio=1&seed=19370702&start=2026-10-20T20%3A00%3A00Z in a browser source. The supplied timestamp is illustrative; replace it with the intended UTC start. All clients using the same start and seed see the same deterministic baseline ensemble and phase according to their wall clocks; in-app counterfactuals are private.

The viewer advances at 1× real wall time. The + 2H PREVIEW control advances only the local client's simulation. Press * for the experimental switchboard. The optional generated engine/radio audio requires browser audio activation and is not a historical recording. The export button downloads synthetic trial metadata as CSV.

Source files: model.js (deterministic synthetic model), app.js (stream control, rendering, export, input and synthetic audio), styles.css, index.html. No network or private data is required.
