## 48H+ / no fixed loop

There is no authored loop or repeating timeline.

- regime lengths are generated from an unbounded era index
- regimes interpolate into newly generated targets
- audio events advance a mutable PRNG rather than a fixed bar sequence
- the visual field contains persistent residue/velocity feedback
- continuous elapsed time enters the field directly
- multiple slow modulators use non-matching rates

Motifs can recur because recurrence is part of the concept, but the system never returns to a fixed authored beginning.

Run start and generative sequence state persist in localStorage. On reload, the long-duration clock/sequence continues while the per-pixel residue begins accumulating again.

## Controls

- `?info=0` hide instrumentation
- `?audio=0` do not autostart audio
- `?fresh=1` begin a new run
- `?rate=N` testing time multiplier
- `SPACE` start/resume audio
- `R` reset run
