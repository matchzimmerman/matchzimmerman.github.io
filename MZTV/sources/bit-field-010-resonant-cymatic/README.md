# MZTV / RESONANT CYMATIC FIELD 010

An ever-evolving browser-source version of the OBAS Chladni/cymatic study.

The system is not a fixed loop. Visual structure and sound share the same long-form state, so changes in resonance, density, tension, motion, harmonic position, and event type affect both domains together.

## Core behavior

- Low-resolution 4-color OBAS field rendered at 480×270 and nearest-neighbor scaled to 1920×1080.
- Chladni/nodal mode pairs migrate through a memory-constrained mode library instead of returning to a fixed 8-second state.
- Rigid linked contours, chevron stress, torsion, compression, folds, and quiet-plate events evolve in long epochs.
- No broad filled emergent blobs; the visual language stays line-, node-, and contour-driven.
- Ambient audio uses a constrained common-tone harmonic family: Dm9, G6/9, Cmaj9, Am9, Em11.
- Higher pad voices, sub roots, saturation, filter brightness, and stereo position are driven by the same shared state that drives the image.
- Changes glide rather than cut, so the work can run as a continuous MZTV performance rather than a repeated clip.
- Evolution memory avoids immediate reuse of recent visual modes and chords.

## OBS

Use the live URL as an OBS Browser Source at 1920×1080. Browser audio is generated with Web Audio. If autoplay is blocked, interact with the source once or use OBS's browser interaction window.

URL options:
- ?hud=0 hides the system/evolution display.
- ?audio=0 prevents automatic audio startup.

Keyboard controls:
- H — toggle HUD
- R — force a new evolution state
- Space — start/resume audio

## Canon

The browser source is the score/instrument. Each uninterrupted MZTV run is a distinct realization because the field's long-form state continues to evolve rather than resolving to a fixed loop.
