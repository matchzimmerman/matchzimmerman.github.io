Project role

A show built as a complete visual + sonic world.

Match Zimmerman developed the overall aesthetic system for The Normal Show, carrying the identity across cover art, channel graphics, episode thumbnails, and the show’s original theme music.

Identity in use

The system stays recognizable while shifting scale, crop, hierarchy, and density across platform formats.

Visual language

Studio green. Warm orange. Hard black. Awkward glamour.

The identity uses deliberately blunt typography, off-register shadowing, cutout edges, studio-backdrop imagery, and the recurring mannequin head as a flexible visual anchor. The result feels like a collision between public-access television, beauty-school display culture, low-budget production design, and a graphic system that knows exactly what it is doing.

Sonic identity

The theme song is part of the branding, not an add-on.

The same project language extends into sound: the original theme music was developed as another piece of the show’s identity system, giving the series a recognizable entrance before the visual frame even settles.
